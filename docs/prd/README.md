O PRD descreve o problema, os públicos, os requisitos e as regras do produto.

Os PDFs do PRD e backlog são gerados dos Markdown. Na raiz do repositório, com Python e `reportlab` instalados, execute `python scripts/gerar-pdfs.py`. Confira a renderização dos dois PDFs após cada alteração. Links relativos são exportados como URLs dos documentos no GitHub.
